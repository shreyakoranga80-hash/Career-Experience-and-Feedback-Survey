# Career-Experience-and-Feedback-Survey
Responsive multi-section survey and data collection form built using semantic HTML5 and CSS, featuring accessible form controls, multiple input types, and native browser validation without external frameworks.

Tech stack:
HTML5
CSS3
Native Form Validation
Responsive Design
Accessibility

Features:
✓ Semantic HTML5 structure
✓ Accessible form controls
✓ Multi-section form architecture
✓ Native browser validation
✓ Radio and checkbox groups
✓ Date/time inputs
✓ File upload
✓ Responsive layout
✓ Mobile-friendly design
✓ No external frameworks
